# Swiss Folio

Swiss Folio is a bold, Swiss-inspired portfolio theme built with Astro and
Tailwind CSS. It is designed for designers, developers, freelancers, and
independent studios who want a focused one-page portfolio.

The theme combines oversized typography, hard grid lines, high-contrast
sections, and a restrained three-color palette. It includes sections for an
introduction, selected projects, testimonials, and press mentions.

## Theme system

- Semantic `paper`, `ink`, and `accent` colors in `global.css`
- Geist and Geist Mono typography
- Shared `Wrapper` and `Text` components
- Responsive Tailwind CSS layouts
- Dependency-free scroll reveals using Intersection Observer
- Reduced-motion support

Content and links can be edited directly inside the landing components in
`src/components/landing`.

## Development

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```
